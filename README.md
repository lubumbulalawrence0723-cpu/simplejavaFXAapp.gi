## How to run

1. Open this folder as a project in IntelliJ IDEA (File -> Open, select the SimpleJavaFXApp folder).
2. Let Gradle finish syncing.
3. Open the Terminal tab inside IntelliJ (View -> Tool Windows -> Terminal).
4. Run:

   ./gradlew run

   (or `gradle run` if you have Gradle installed globally)

5. A window titled "My First JavaFX Application" should open with a "Welcome to JavaFX!" label
   and a "Click Me" button. Clicking the button changes the message.
